# Leap App

A full-stack application built with Leap.new using Encore.ts for the backend and React with TypeScript for the frontend.

## Features

- Backend: Encore.ts REST APIs
- Frontend: React + TypeScript + Vite + Tailwind CSS
- Auto-generated type-safe API client

## Development

This app runs automatically on Leap.new. No manual setup required.
